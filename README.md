# 轻记 · 记账本

一个纯前端的个人记账应用，单文件即可运行，数据保存在浏览器本地。

## 功能

- 用户注册 / 登录，多账户数据隔离
- 记一笔：收入 / 支出、分类、备注、日期、凭证图片上传
- 总览：月度收支、预算进度、支出分类环形图
- 明细：按日期分组、类型/分类/月份筛选、备注搜索
- 统计：近 6 个月收支趋势、分类占比
- 设置：预算管理、CSV 导入导出、清空数据

## 使用

直接用浏览器打开 `index.html` 即可，无需安装依赖或启动服务。

## 技术说明

- 数据存储：`localStorage`（用户、账单、预算）+ `IndexedDB`（凭证图片）
- 无外部依赖，所有 CSS / JS 内联在单文件中
- 数据仅保存在当前浏览器本地，不跨设备同步

## 注意

密码采用本地简易哈希存储，仅适合个人本地使用，请勿用于敏感数据。
